# Cosmica - GPS Tracking System

This is a full-stack project with separate frontend and backend.

## Project Structure

- `frontend/`: React + Vite frontend.
- `backend/`: Express.js + MongoDB backend.

## How to Run

### 1. Run the Backend

```bash
cd backend
npm run dev
```

### 2. Run the Frontend

```bash
cd frontend
npm run dev
```

The backend will run on `http://localhost:5000` and the frontend on `http://localhost:5173` (default Vite port).
